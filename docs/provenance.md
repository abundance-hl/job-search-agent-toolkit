# Where this toolkit came from

Prepared on **October 27, 2026** from an established resume-building workspace and seven related agent conversations. The conversations were reviewed privately to recover the workflow; their titles, applicant identity, target employers, transcripts, and internal identifiers are not distributed.

## Workflows recovered

| Area | Contribution |
| --- | --- |
| Resume generation | A factual Markdown master, reusable robotics / sales-engineering / crypto profiles, a LaTeX renderer, PDF extraction checks, and visual review. |
| Research setup | LinkedIn MCP read-tool restrictions, one folder per role, a master job list, posting-ID deduplication, and detailed research prompts. |
| Application drafts | Role-specific resumes, cover letters, application-answer drafts, fit analysis, source records, and manual review checklists. |
| Evidence boundaries | Distinguishing direct experience from transferable experience and AI-assisted direction from personally writing code. |
| Interview preparation | Attributed company research, technical discovery scenarios, evidence-backed stories, and prioritized questions. |

## What existed before the shareable edition

The original workspace contained `AGENTS.md`, build/validation scripts, JSON profiles, role folders, and structured prompts. No custom job-search `SKILL.md` files were recovered. The original work used existing PDF, document, browser, and connected-drive tools.

The three skills here are **newly extracted from those established workflows**, with setup documentation, generic templates, and portability changes. Bundled product/plugin skills and third-party server code are linked where useful, not redistributed.

The public sample resumes are anonymized illustrative adaptations. Identifying content is omitted or generalized, and the samples are not evidence for another applicant's qualifications or a claim that any particular job is open. Every user supplies and approves their own factual master.

## External dependencies

- [LinkedIn MCP Server](https://github.com/stickerdaniel/linkedin-mcp-server): independent upstream project, rechecked October 27, 2026. The full tool set includes writes; this toolkit uses an explicit read-tool allowlist. Each person authenticates locally.
- [Official skills guidance](https://learn.chatgpt.com/docs/customization/overview#skills): repository skill discovery and invocation.
- [Official MCP guidance](https://learn.chatgpt.com/docs/extend/mcp): client configuration.
- [Tectonic](https://tectonic-typesetting.github.io/): LaTeX-to-PDF rendering.
- [Poppler](https://poppler.freedesktop.org/): page rendering for visual inspection.

No original account sessions, private correspondence, application history, or personal configuration are included.
