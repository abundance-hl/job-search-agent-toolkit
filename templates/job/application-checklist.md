# Application review checklist

## Agent checks

- [ ] The exact posting and stable ID are recorded; duplicate roles are reconciled.
- [ ] Current requirements were checked and source dates recorded.
- [ ] Every candidate claim maps to the user's factual source or documented clarification.
- [ ] Titles, dates, ownership, metric qualifiers and contact details remain accurate.
- [ ] Tailored source and profile are saved; the reusable master was preserved.
- [ ] The resume PDF built successfully and its text extraction was checked.
- [ ] Every rendered page was visually inspected; any limitation is recorded.
- [ ] Letter and message drafts contain no invented relationships or achievements.
- [ ] No live application or outreach action was performed.
